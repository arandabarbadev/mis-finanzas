# 💶 Mis Finanzas

Web para controlar mis ingresos y gastos, hecha por Rafa.

🔗 https://arandabarbadev.github.io/mis-finanzas/

## Qué hace

- Añadir ingresos y gastos con concepto, categoría y fecha
- Balance total y resumen de cada mes (ingresos, gastos, balance)
- Lista de movimientos con editar y borrar
- Gastos por categoría y gráfico de los últimos 6 meses
- Los datos se guardan en el navegador (localStorage)
- Se puede instalar como app en el móvil (PWA)
